# 🐍 Python Daily Bites

A collection of small, self-contained Python scripts — one added (almost)
every day. Each "bite" is a mini tool or exercise focused on practicing a
specific concept: loops, functions, file I/O, APIs, and more.

The goal isn't big, polished software — it's consistency. Small daily
progress, real commits, real learning.

## 📅 Daily Log

| Day | Script | Description | Concepts |
|-----|--------|-------------|----------|
| 01 | [`day01_todo_list.py`](./day01_todo_list.py) | Command-line to-do list with add/view/complete/delete, saved to a local file | file I/O, functions, loops |

## 🚀 How to Run

Each script is standalone. Clone the repo and run any script directly with Python:

```bash
git clone https://github.com/rattaneshguleria/python-daily-bites.git
cd python-daily-bites
python day01_todo_list.py
```

Requires Python 3.
